Méthode 1 : Démarrage Automatique avec Docker (1-Click)
⚡ Exécution Complète en 1 Seule Commande
Recommandé & Le plus Rapide

Cette méthode télécharge, compile et lance automatiquement la Base de Données, l'API .NET 9, le Frontend Angular et phpMyAdmin sans aucune configuration manuelle.

1
Ouvrir le terminal à la racine du projet :
# Aller dans le dossier du projet
cd /chemin/vers/ReservationSystem
2
Lancer tous les conteneurs avec Docker Compose :
docker-compose up -d --build
✅ C'est tout ! Docker va créer la base de données, insérer le schéma script.sql, créer l'utilisateur Admin et démarrer le serveur Nginx.
3
Accéder à vos applications dans le navigateur :
Service URL Locale Identifiants par défaut
🌐 Application Web http://localhost:8080 admin / admin123
⚙️ Backend API http://localhost:5000 Endpoints /api/*
🗄️ phpMyAdmin http://localhost:8081 Serveur: db | User: root | Pass: rootpassword
4
Commandes Docker utiles :
# Voir l'état des conteneurs
docker ps

# Voir les logs en direct
docker-compose logs -f

# Arrêter les conteneurs
docker-compose down

Méthode 2 : Démarrage Manuel Sans Docker (Mode Développement)
💻 Développement Local (Live Reload & Debugging)
Mode Développeur
A
Étape 1 : Préparer la Base de Données (MySQL / MariaDB)

1. Démarrez votre serveur MySQL local (via XAMPP, Homebrew, ou service MySQL standard).
2. Ouvrez phpMyAdmin ou votre client MySQL (ex: DBeaver, TablePlus, Workbench).
3. Créez une nouvelle base de données nommée ReservationSystemDb.
4. Importez le fichier SQL situé dans : Server/script.sql.

B
Étape 2 : Lancer le Backend (.NET 9 Web API)

Vérifiez la chaîne de connexion dans Server/appsettings.json :

"DefaultConnection": "Server=localhost;Port=3306;Database=ReservationSystemDb;User=root;Password=;"

Ouvrez un premier terminal et exécutez les commandes suivantes :

# 1. Aller dans le dossier Server
cd Server

# 2. Restaurer les packages NuGet
dotnet restore

# 3. Lancer l'API Backend
dotnet run
👉 Le Backend démarrera sur http://localhost:5000. L'interface Swagger de documentation API est accessible sur http://localhost:5000/swagger.
C
Étape 3 : Lancer le Frontend (Angular 19)

Ouvrez un deuxième terminal et exécutez les commandes suivantes :

# 1. Aller dans le dossier App
cd App

# 2. Installer les modules npm (avec legacy-peer-deps)
npm install --legacy-peer-deps

# 3. Démarrer le serveur de développement Angular
npm start
👉 Le Frontend s'ouvrira sur http://localhost:4200 avec le rafraîchissement automatique en temps réel à chaque modification du code source.

Résolution des Problèmes Fréquents (Troubleshooting)
Problème rencontré Cause probable & Solution
Port 3306 déjà occupé
Error: bind: address already in use		 Un service MySQL local tourne déjà sur le port 3306.
Solution : Le fichier docker-compose.yml est déjà configuré pour exposer la BDD sur le port 3307:3306 pour éviter tout conflit.
Erreur d'installation npm
ERESOLVE unable to resolve dependency tree		 Incompatibilité de dépendances mineures entre packages Angular.
Solution : Toujours utiliser le flag : npm install --legacy-peer-deps.
Page Blanche / Connexion Échouée
sur http://localhost:8080		 Le conteneur Backend met quelques secondes pour migrer la BDD.
Solution : Patientez 10 secondes et faites un Hard Refresh (Cmd+Shift+R ou Ctrl+F5).
Rebuild complet après modification Pour forcer Docker à recompiler le code modifié :
docker-compose down && docker-compose up -d --build
